SHOPEASY BASIC SHOPPING WEBSITE

Files:
- index.html  -> Main website/front page
- style.css   -> Website styling
- script.js   -> Login popup and basic demo login

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click Login to see the login form.
4. Enter any valid email and password for the demo login.

Note:
This is a front-end demo. The login does not connect to a real database or authentication server.
